1. Settings

Warning: Type the key on this device only. Never type the key in a chat or an email.

Privacy: The page keeps the key in the storage of this browser. The page sends your voice recordings to Microsoft for the speech scores. The page does not keep recordings.

2. Speech score test

Choose a sentence. Tap Record. Say the sentence. Stop at the end of the sentence.

Use the default first. Change this value only if a pause stops the recording too early.
